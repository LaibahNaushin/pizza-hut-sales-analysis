# 🍕 Pizza Hut Sales Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing Pizza Hut sales data using SQL to uncover valuable business insights and understand customer purchasing patterns.

The analysis includes order trends, revenue, pizza performance, category-wise sales, and other important sales metrics.

## 🎯 Project Objectives

The main objectives of this project are:

- Calculate the total number of orders placed
- Calculate total revenue generated from pizza sales
- Identify the highest-priced pizza
- Find the top 5 most ordered pizza types
- Identify the most commonly ordered pizza size
- Analyze quantity ordered by pizza category
- Analyze order distribution by hour of the day
- Analyze category-wise pizza distribution
- Calculate the average number of pizzas ordered per day
- Identify the top 3 pizza types based on revenue
- Calculate the percentage contribution of each pizza type to total revenue
- Analyze cumulative revenue over time
- Find the top 3 pizza types by revenue within each pizza category

## 🛠️ Tools & Technologies

- SQL
- SQL Joins
- Aggregate Functions
- GROUP BY
- ORDER BY
- Subqueries
- Data Analysis

## 📊 Analysis Performed

### 1. Order Analysis
Calculated the total number of orders placed and analyzed order patterns.

### 2. Revenue Analysis
Calculated total revenue generated from pizza sales and analyzed revenue contribution.

### 3. Product Analysis
Identified:
- Highest-priced pizza
- Most ordered pizza types
- Most common pizza size
- Top revenue-generating pizzas

### 4. Category Analysis
Analyzed pizza categories based on:
- Total quantity ordered
- Pizza distribution
- Revenue performance

### 5. Time-Based Analysis
Analyzed:
- Orders by hour of the day
- Average pizzas ordered per day
- Cumulative revenue over time

## 💡 Key Insights

The project helps understand:

- Which pizzas are ordered most frequently
- Which pizza types generate the most revenue
- How different pizza categories perform
- Customer ordering patterns throughout the day
- Revenue contribution of individual pizza types
- Sales performance over time
